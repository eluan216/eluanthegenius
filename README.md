## Site

A buildless, responsive HTML portfolio, retaining the warm editorial visual identity. Content and CSS live in `index.html`; no JavaScript is required for navigation, services, projects, contact, or FAQs. The JSON-LD script supplies descriptive structured data only.

- Six clearly scoped AI, ML, data, sensor, and biomedical research service offers.
- Featured work: NeuralForge, LocalCodeGraph, Elite Data Intelligence, and ECG arrhythmia research.
- Canonical URL, social metadata, Person/ProfilePage/WebSite/ItemList structured data, and sitemap.
- Keyboard skip link, visible focus, semantic main landmark, and reduced-motion support.
- Existing Google verification file is retained.

## Preview

From this directory, run `python -m http.server 8000` and open http://localhost:8000.

Deploy through the existing GitHub Pages configuration. This is a project site: all local assets use relative URLs so they resolve beneath `/eluanthegenius/`.

## Content maintenance

Keep project descriptions aligned with their public source and measured reports. Do not turn synthetic demonstrations, development benchmarks, or research prototypes into claims of client outcomes or clinical readiness. Confirm resume and demo links periodically.

## Search visibility after deployment

1. In Google Search Console, verify the URL-prefix property `https://eluan216.github.io/eluanthegenius/` using the retained verification file.
2. Submit `https://eluan216.github.io/eluanthegenius/sitemap.xml`.
3. Inspect the canonical homepage URL and request indexing after checking the live page.
4. Monitor indexing and search queries for the full name, Eluan the Genius, and relevant services. Compare impressions, clicks, and enquiries over time.
5. Keep public GitHub and LinkedIn profile links consistent with this canonical URL.

Google reads robots.txt only at the host root (`https://eluan216.github.io/robots.txt`). A robots.txt in this project directory would not control crawling. Manage any host-level crawl directives in the user-site repository if one exists.

No ranking or indexing is guaranteed. Structured data describes visible facts and does not guarantee a rich result. No fabricated reviews, rankings, clients, or performance claims are included.
