Selected engineering work

Systems with evidence behind them

A selection of my public projects, chosen for implementation depth, reproducibility, and the problems they explore. Each repository explains what works and what still needs validation.

01

NeuralForge

Flagship · C++20 / local ML

A native inference and local-learning toolkit for CPU applications. I built a C++20 core, C API, deployment bundles, checkpoint resume, candidate evaluation, and rollback.

Evidence: participant-held-out UCI HAR evaluation, numerical comparisons with PyTorch, and x86-to-ARM64 artifact checks. The logistic regression baseline is stronger on this task; physical-device measurements remain future work.

C++20C APICMakePythonARM64

02

LocalCodeGraph

Code retrieval · reproducible evaluation

An offline repository-context toolkit for coding agents. Python AST indexing, SQLite storage, BM25 retrieval, optional dense search, and bounded dependency expansion help select code within a fixed context budget.

Evidence: budget-matched comparisons on 23 SWE-bench Lite development tasks. Changed-file hits tie BM25 at 11/23; a separate post-hoc pilot produced one test-verified BM25 repair. No graph superiority claim.

Elite Data Intelligence

My consulting and software project brings together a browser-local CSV workbench and a bring-your-own-key AI workspace with 15 specialist roles, structured outputs, and human review.

ECG arrhythmia research

Biomedical ML · research only

A patient-separated ECG classification study with Random Forest and CNN comparisons, error analysis, a waveform explorer, and a FastAPI inference prototype.

Evidence: measured MIT-BIH comparisons and external/noise evaluations with documented limitations. Minority-class performance remains weak. Research and education only; not a medical device.
